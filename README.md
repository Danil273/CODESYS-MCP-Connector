# CODESYS MCP Connector

Коннектор, через который нейросеть (Claude Code, приложение Claude, Codex CLI и другие MCP-клиенты) работает прямо в открытом у вас окне CODESYS: создаёт и правит функциональные блоки и программы, собирает проект, разбирает ошибки, ищет, где используется переменная. Все изменения сразу видны в CODESYS, а вы продолжаете работать в нём как обычно.

Внутри — MCP-сервер [Codesys-MCP-Master](https://github.com/phobicdotno/Codesys-MCP-Master) 0.19.0 (MIT) с тремя исправлениями: кириллица в путях и комментариях, работа из приложения Claude и переход между чатами. Подробно — `AGENTS.md`, раздел 6.

## Что нужно

- Windows 10 или 11.
- CODESYS 3.5 (SP18, SP19, SP21 или SP22). Проверено на SP21 Patch 1.
- [Node.js](https://nodejs.org) 18 или новее (LTS).
- Claude Code — в приложении Claude (вкладка Code) или в терминале. Подойдёт и другой MCP-клиент.
- Интернет — один раз, при установке.

## Установка

1. Положите папку коннектора в место без кириллицы и OneDrive, например `C:\Tools\CODESYS-MCP-Connector`:
   ```
   git clone https://github.com/Danil273/CODESYS-MCP-Connector C:\Tools\CODESYS-MCP-Connector
   ```
   или на GitHub «Code → Download ZIP» и распакуйте туда. Потом папку не переносите: путь запоминается при установке.
2. Запустите `install.cmd` двойным щелчком (если Windows спросит про файл из интернета — «Выполнить»). Скрипт поставит зависимости, покажет найденные CODESYS и подключит коннектор к Claude Code.
3. Перезапустите приложение Claude.

Можно поручить установку нейросети: откройте папку коннектора в Claude Code и напишите «Установи коннектор по AGENTS.md».

## Как работать

1. Откройте свой проект в CODESYS сами — двойным щелчком по `.project`.
2. Напишите в чате: «Подключись к CODESYS». Через пару секунд в конце заголовка окна CODESYS появится `[MCP]`.
3. Дальше просите словами: «создай ФБ управления насосом с входами пуск и стоп», «собери проект и исправь ошибки», «где используется nSpeed?».
4. В конце: «отключись от CODESYS». Окно и проект остаются открытыми.

Чтобы нейросеть в каждом новом чате знала эти правила, добавьте `templates\PROJECT-RULES.md` в файл `CLAUDE.md` папки, где вы работаете с проектом (или попросите нейросеть сделать это).

Важно:

- **CODESYS открываете вы, а не нейросеть.** CODESYS, запущенный из чата, закроется вместе с этим чатом.
- **Одно окно CODESYS — один чат.** Если окно уже подключено в другом чате, нейросеть скажет об этом; отключитесь там или закройте тот чат.
- **ПЛК нейросеть не трогает**, пока вы прямо не попросите: загрузка, запись переменных, старт и стоп.
- **Не держите в CODESYS открытых диалогов**, когда нейросеть работает: они блокируют выполнение команд.

## Если не подключается

- Подключите вручную: в CODESYS «Инструменты → Скриптинг → Выполнить файл скрипта…» и выберите `C:\Users\<ваше имя>\AppData\Local\Temp\Codesys-MCP-Master\attach-codesys-mcp.py`. Точный путь нейросеть скажет сама.
- В чате нет инструментов `codesys-master` — перезапустите приложение Claude. Не помогло — запустите `install.cmd` ещё раз и посмотрите, что он пишет.
- Остальные случаи — таблица в `AGENTS.md`, раздел 4. Можно просто попросить нейросеть: «Разберись, почему не подключается CODESYS, по AGENTS.md».

## Что в папке

| Путь | Что это |
|---|---|
| `README.md` | Этот файл, для человека |
| `AGENTS.md` | Инструкция для нейросети: установка, работа, устройство, диагностика |
| `CLAUDE.md` | Подключает `AGENTS.md` для Claude Code, открытого в этой папке |
| `install.cmd`, `install.ps1` | Установка и регистрация сервера |
| `templates/PROJECT-RULES.md` | Правила работы — вставить в `CLAUDE.md` вашего проекта |
| `extras/git-autopush/` | Необязательно: git-коммит и push после каждой правки через нейросеть |
| `patches/local-fixes.patch` | Исправления относительно оригинального сервера |
| `server/` | Сам MCP-сервер: готовая сборка `dist/`, исходники `src/`, документация `docs/` (англ.) |
