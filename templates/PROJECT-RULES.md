## CODESYS через MCP `codesys-master`

- Проект: `<полный путь к .project>`, CODESYS `<версия, например 3.5 SP21 Patch 1>`.
- CODESYS открывает только пользователь (двойной щелчок по `.project`). Не запускать его через MCP (`launch_codesys`, `launch_codesys_with_project`): такой CODESYS — дочерний процесс чата, закроется вместе с ним, а другой чат его не подхватит.
- Начало работы — `attach_codesys` без параметров. Успех: ответ «Attached to CODESYS …», в конце заголовка окна `[MCP]`. До успешного attach других инструментов `codesys-master` не вызывать: без подключённого окна они сами запустят новый CODESYS.
- Открыто несколько CODESYS — attach вернёт список: спросить пользователя, какое окно, и повторить с `pid`.
- Автоматика attach не сработала — попросить закрыть диалоги в CODESYS и повторить. Не помогло — `attach_codesys` с `auto: false`, а пользователю дать полный путь `%TEMP%\Codesys-MCP-Master\attach-codesys-mcp.py` для Инструменты → Скриптинг → Выполнить файл скрипта.
- С одним CODESYS работает один чат. Ответ «used by another live MCP session» не обходить: сказать пользователю, что окно занято другим чатом, и предложить отключиться там (`shutdown_codesys`) или закрыть тот чат.
- Конец работы — `shutdown_codesys`: только отключает, окно и проект остаются.
- `create_pou` и `set_pou_code` сохраняют проект сами. Объявление и реализацию отправлять одним вызовом `set_pou_code`.
- Пути объектов: `Application/<Папка>/<Имя>`.
- Код одного POU — `get_text_lines`, точечная правка — `edit_text_lines`. `get_all_pou_code` на большом проекте не вызывать: выгружает весь проект, это очень много токенов.
- Где используется имя — `find_references`; переименование во всём проекте — `rename_symbol`.
- В конце правок — одна `compile_project`. Сообщения копятся с открытия проекта, поэтому старые ошибки в ответе не значат, что проект сломан сейчас.
- ПЛК не трогать без явной просьбы: `connect_to_device`, `download_to_device`, `write_variable(s)`, `force_variables`, `start_stop_application`, `reset_application`, `set_device_state`, `set_simulation_mode`.
- Кириллица в путях и комментариях поддерживается.
- Установка, устройство коннектора и диагностика — `AGENTS.md` в папке коннектора (`<путь к CODESYS-MCP-Connector>`).
